GRCBuddy 🚀
Touching Hearts, Renewing Minds — A real-time student matching and wellness chat platform for Global Reciprocal Colleges.

📖 Overview
GRCBuddy is a modern, real-time web application designed to connect GRC students based on shared interests. Whether looking for a study buddy, a random chat, or specific academic discussions, GRCBuddy facilitates anonymous connections through a streamlined matching system.

✨ Features
Smart Matching: Users select 3–5 interests and are automatically paired with others using Firestore's array-contains-any logic.

Real-time Chat: Seamless, low-latency messaging powered by Firebase Cloud Firestore.

Course-Specific Topics: Tailored interest lists for BSIT, BSBA, Accountancy, Education, and Entrepreneurship.

Responsive UI: A clean, mobile-first design utilizing Tailwind CSS with support for dark mode.

Identity Privacy: Students use nicknames and year levels to maintain a comfortable, anonymous environment.

🛠️ Tech Stack
Frontend: React.js

Styling: Tailwind CSS

Icons: Lucide-React

Backend/Database: Firebase Firestore

Deployment: GitHub Pages

State Management: React Hooks (useState, useEffect)
